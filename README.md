# Game UI Prompt Lab

게임 UI 디자인을 13단계로 고르면서 결과를 실시간 게임 화면으로 확인하고, 이미지 생성 AI와 코딩 AI에 넣을 프롬프트를 만드는 도구입니다.

사용: https://brownleaf0215.github.io/game-ui-prompt-lab/

`index.html` 파일 하나로 동작합니다. 외부 요청이 없어서 내려받아 오프라인으로 열어도 같게 작동합니다.

## 13단계

플레이 플랫폼, 화면 비율, 개발 환경, 게임 장르, 화면 종류, 시각 스타일, 색 조합, 재질과 표현, 형태 언어, 화면 구성, 상호작용, 정보 밀도를 차례로 고르고 마지막 단계에서 프롬프트를 받습니다. 단계마다 고르는 이유와 시각 샘플이 있고, 선택지 검색과 직접 입력을 쓸 수 있습니다. 직접 입력한 내용은 프롬프트에 그대로 들어갑니다. `←` `→`로 단계를 옮기고 숫자 키로 선택합니다.

## 실시간 미리보기

13종의 화면(메인 메뉴, 인게임 HUD, 인벤토리, 상점, 뽑기, 결과, 스테이지 선택, 설정, 대화, 로딩, 캐릭터, 임무, 팝업)을 HTML과 CSS로 그립니다. 장르에 맞는 예시 내용이 들어가고 슬롯, 탭, 토글, 슬라이더를 직접 눌러 볼 수 있습니다.

- 비율, 14개 색 역할, 재질, 형태, 구성, 밀도, 글꼴, 상호작용 선택이 바로 화면에 반영됩니다.
- 자동 시연 커서가 화면을 눌러 보여 줍니다. 직접 조작하면 멈추고, 동작 줄이기 설정을 켠 환경에서는 처음부터 꺼집니다.
- 버튼·상태 테스트 탭에서 부품 7종의 기본, 호버, 눌림, 포커스, 선택됨, 비활성, 로딩을 한 표로 비교합니다.
- 맞춤과 100% 확대, 기기 프레임 전환, 단독 실행 HTML 저장을 지원합니다.

## 출력

| 대상 | 내용 |
|---|---|
| 자연어 이미지 AI | GPT 이미지, Gemini, Ideogram 등에 쓰는 문장형 프롬프트 |
| Midjourney | 키워드와 `--ar`, `--no` 파라미터 |
| Stable Diffusion | 태그와 네거티브 프롬프트 |
| Unity UI Toolkit | UXML, USS, C#, PanelSettings, 안전 영역 요청 명세 |
| Unity uGUI | 에디터 스크립트, Canvas Scaler, TextMeshPro 요청 명세 |
| Unreal UMG | 위젯 블루프린트와 C++ 바인딩 요청 명세 |
| Godot | Control 노드와 Theme 요청 명세 |
| HTML/CSS, React | 단일 파일 또는 CSS Modules 컴포넌트 요청 명세 |
| 디자인 토큰 | CSS 변수, Unity USS, JSON |

코딩 AI용 프롬프트에는 14개 색 토큰, 글꼴, 모서리 반경, 간격, 상태별 표현, 안전 영역, 기준 해상도, 출력 형식이 들어갑니다. 출력 언어는 한국어와 영어 중에서 고릅니다. 이미지 AI는 영어 프롬프트를 더 정확하게 따릅니다.

## 그 밖의 기능

- 되돌리기와 다시하기(`Ctrl+Z`, `Ctrl+Shift+Z`), 브라우저 자동 저장
- 스타일 프리셋 10종, 단계별 잠금이 되는 무작위 조합
- 상세 정보: 글꼴과 글자 크기, 14부위 RGB 색상표와 WCAG 대비 판정, 장르와 기기로 거르는 레퍼런스 34개, 내 커스텀 디자인 저장
- 저장한 디자인 2~4개를 나란히 보는 비교 모드
- 상태를 주소에 담는 공유 링크
- 프롬프트 복사 기록과 JSON 백업 저장·불러오기
- 낮은 대비, 모바일의 21:9, 이미지 AI에 너무 많은 요소 같은 조합을 알려 주는 품질 힌트

## 알아 둘 점

- 미리보기는 기기에 설치된 글꼴을 씁니다. 지정한 글꼴이 없으면 비슷한 시스템 글꼴로 보이고, 프롬프트에는 고른 글꼴 이름이 그대로 들어갑니다.
- 소리 느낌은 프롬프트의 문구로만 들어가고 미리보기에서 소리가 나지 않습니다.
- 데이터는 브라우저 localStorage에만 저장됩니다.
- 레퍼런스에는 게임 이름과 공식 사이트 링크만 있고 실제 게임 이미지는 없습니다.
